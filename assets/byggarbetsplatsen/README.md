# Byggarbetsplatsen: original Blender asset kit

Style reference: user-approved sunny cartoon construction yard, 8 November 2026. All machine and scenery geometry is original, generated and exported by Blender 4.3.2; no vehicle brands. Existing core game/save schema remains version 1.

## Rebuild

```
OMP_NUM_THREADS=2 blender -b -t 2 --python assets/byggarbetsplatsen/blender/build.py
OMP_NUM_THREADS=2 blender -b -t 2 --python assets/byggarbetsplatsen/blender/export-low.py
```

`blender/construction.blend` contains the six editable vehicles, environment kit, all six projects and thumbnail studio. `models/*.glb` are game exports. `*-low.glb` are reduced meshes with identical node contracts. `thumbnails/` are actual Cycles renders of these models, not concept-art stand-ins. Reproducible meshes retain UVs generated by Blender primitives; the terrain's repeatable grain is generated locally at runtime (no downloaded textures). Material colors, roughness and metalness are embedded in GLB. No external texture requests are needed.

## Coordinates and pivots

One Blender unit = one metre. Authoring helpers use game coordinates `(x,y,z)` = right/up/back; Blender conversion `(x,-z,y)` and glTF Y-up export restore game axes. Vehicles face -Z. Use the saved Blender file as the high-detail editable source; GLBs merge only fixed meshes sharing a material and parent.

- `upper`: yaw around chassis slew ring; `boom`, `stick`, `scoop`: local X hinge rotations.
- `bed`: front hinge of tracked dumper; positive X rotation raises its rear.
- `wheel*`: local X axles; `wheel_radius` extra controls angular velocity.
- `track_L/R_*`: continuous racetrack tread path using `track_phase`, `track_half`, `track_x` extras.
- `hydraulic_*`: barrel plus separate `_rod`, endpoint object names stored in extras. Adapter aligns both every frame.
- `hook`: cancels boom world rotation so cable remains vertical; cable and block move separately.
- `drum`: local Y mixing rotation after initial tilt. `scoop` on mixer is the chute.
- `load`: isolated cargo node. Project parts cloned from the actual next installable node.
- `part_0..8`: four walls/towers/piers; two roofs/slides/decks; three final installations. Existing core counts determine visibility.

Blender unique-name suffixes are resolved from GLTF `userData.name`, not Three.js sanitized names. Code is in `games/byggarbetsplatsen/assets.js`. Core state and material conservation are owned exclusively by `core.js`.

## Lighting and performance

Warm directional sun, cool hemisphere fill, ACES exposure, separate enamel/rubber/steel/glass/timber/earth roughness. Shadow resolution 2048 on high; low mode disables dynamic shadows and caps pixel ratio to 1. Glass does not write depth or cast solid shadows. Repeated exported geometry is shared across clones; static opaque scenery is merged by material. Dynamic moving parts retain their individual pivots. Terrain grain is tiled, not baked onto movable objects.
