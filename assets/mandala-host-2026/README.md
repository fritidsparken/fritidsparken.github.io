# Egna färgläggningsbilder: Höst

27 originalmotiv skapade med det inbyggda bildgenereringsverktyget. Varje motiv har en helsidesförhandsbild och en separat A4-PDF.

Stil: svart konturteckning på vit bakgrund, tydliga slutna färgläggningsytor, inga färger, skuggor, texter eller vattenmärken. Stående A4 med utskriftsmarginaler. Halloweenmotiven är lekfulla och barnvänliga.
